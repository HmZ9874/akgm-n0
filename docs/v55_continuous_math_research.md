# V55 持续数学语义研究

V55 将固定复演改成持久化研究活动。每次启动都会读取上一次经过验证的状态，从尚未进入成功库的精确行为继续搜索；发现通过证明后成为下一轮可调用原语，并在进程结束前原子保存状态。

## 运行

在项目根目录执行：

```powershell
python .\scripts\run_autonomous_math_research_v55.py
```

默认每次以“至少 5 个新验证语义”为目标，最多运行 12 轮。可以调整本次目标，但不能超过冻结的 12 轮边界：

```powershell
python .\scripts\run_autonomous_math_research_v55.py --target-new 10 --max-rounds 12
```

不要删除状态文件来追求看似更多的发现；删除状态会让活动重新从零开始并重复旧知识。

## 持续性

- 第一次正式运行：从 0 开始，晋升 8 个精确语义。
- 第二次正式运行：加载第一次状态，再晋升 8 个不重复语义。
- 当前正式活动：2 次运行、2 个全局研究轮次、共 16 个验证语义。
- 第二次运行的接受条件：11/11。

## 什么算作新发现

V55 不再仅用有限样本输出作为身份。它把每个自然数计数程序转换成精确符号正规形，覆盖：

- 所有自然数输入；
- 一元与二元参数；
- 二元参数指向不同计数器或同一个计数器的全部别名情况；
- 部分程序的精确定义域和空计数器递减错误；
- 常量、输入偏移和复合动态原语。

只有精确行为签名未进入成功库、运行时证书可重放、符号正规形证明通过的候选才会晋升。

第二次运行的一个结果可事后写成：

```text
不同计数器：n0 >= 1 时，(n0, n1) -> (n0 - 1, n1 + 1)
同一计数器：n0 >= 1 时，n0 -> n0
```

学习器搜索时没有得到该公式或数学名称；文字公式是验证后的翻译。

## 当前边界

这些发现是新的、精确且可执行的计数状态变换，含义是“此前不在本次 V55 活动的知识库中”。它们不自动等于人类未知数学。当前生成器仍限定在自然数计数器、一元底层指令、最多二元参数和三个课程层级；当最终层级连续无新语义时，程序会如实报告饱和，而不会伪造发现。

研究运行只使用本机 Python、CPU、内存和硬盘，不调用云端模型，API token 消耗为零；网页不会修改。
